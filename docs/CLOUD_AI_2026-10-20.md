# 云端 AI 评分接入与验收

本次仅处理云端与本地版差异中的第一项 AI 评分，不接入题库导入、多题库导航、广场或管理员页面，也不修改本地 Web checkout 或固定快照。

## 实现

- 在云端适配本地 `AiGradingService`、评分输入、目标小问和结果确认逻辑；模型调用由浏览器完成。沿用题目、答案、提交代次、人工评分和任务幂等校验。
- 服务器为当前浏览器页面发放单次调用凭据，准备题干、答案、参考答案及受控图片。准备、任务状态、确认与最终成绩全部进入原存储检查点和配额事务；没有后台写盘或服务端模型请求。
- API Key 留在 AI 设置 iframe 的模块内存中，或由用户口令加密保存在当前浏览器；父页仅获得启用状态。iframe 只接受同源父窗口的消息，评分前重新核对登录身份。模型请求使用 HTTPS、禁止重定向、不携带 Hub Cookie。模型响应中的 Key 回显会被移除，模型错误原文不上传。
- 支持题卡手动评分、提交后自动评分、多个小问分别评分、交卷后评分、手动重试与人工改分。模型调用不自动重试；仅结果保存可重试同一份结果一次。关闭页面、超时或未领取任务中断后不静默追加收费请求。
- 模型设置支持 JSON、严格 Schema 与文本兼容模式。模型测试包含文字连接、评分格式及随机图片识别，最多 3 次调用。图片通过仅代表基础识别；模型变化使旧测试结论失效。测试报告随本地加密配置保存。

使用 localhost:4325 独立数据目录与合成用户，通过测试夹具模拟模型响应；未使用用户真实 Key，未调用计费模型，未改变用户真实题库或作答。已通过设置填写、三项能力测试展示、启用自动评分、简答输入提交、自动保存 4/5 与反馈。真实供应商的 CORS、网络、计费与复杂图片识别需要配置该供应商后实际验证。

手动重新评分、刷新后恢复成绩也已通过浏览器检查。已修复云端题卡初始化期间过早查询 AI 任务造成的“当前题卡未处于活动状态”提示；修改仅在云端响应适配层，本地代码和固定快照保持原样。
