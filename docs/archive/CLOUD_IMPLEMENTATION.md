# QuizForge Hub 云端版实现清单

## 产品边界

- 云端产品统一为 QuizForge Hub，扩展现有 Hub，不建立第三套产品或独立账户。
- Hub 包含题库广场、我的云端题库、在线练习、AI 设置和管理员后台。
- 公共题库可“下载到云端”并直接使用；保留用户私人上传和管理员向指定用户交付私人题库。私人内容不进入公共广场。
- 本地产品为 QuizForge，由其他会话维护。本会话在实现本地下载时提供唤醒协议、接口、文件校验和验收约定，当前不改本地启动器。
- 本地下载以唤醒客户端、客户端下载并导入为主要流程；`.qbank` 文件下载保留为备用。未获得客户端结果前，网页不宣称导入成功。

## 当前完成：账户与资源管理基础

- `CLOUD_ENABLED=1` 启用 `/cloud/`、`/cloud/ai`、`/cloud/admin`；默认关闭，不影响已有部署。
- 复用 Hub 会话与管理员权限；普通用户只能读取自己的资源状态，管理员可以分页查询用户、调整默认或指定用户额度、查看审计。
- 每个用户的存储、日下载流量可单独覆盖；`null` 表示跟随站点默认值。旧月度字段保留兼容，但不再执行个人月度限额。
- 调整记录包含实际操作者、目标用户、修改前后额度、原因和时间。调低额度不清空计数、不删除文件。
- SQLite 事务提供用户与站点存储预留、实际占用提交、失败释放、过期拒绝及删除扣减原语，防止重叠预留透支。
- 登录后的现有 Hub 题库附件、截图下载，在同一事务内共同预留站点、IP、用户流量；失败共同回滚。匿名下载继续使用现有站点/IP 限额。
- 日/月计数按 `BILLING_TIMEZONE`（默认 Asia/Shanghai）生成，跨重启保留。

**当前限制：**存储已接入展开后的题库、拓展、图片和练习数据，验证缓存与临时回滚副本作为平台成本单独保留。个人流量额度用于题库文件下载与导出；正常练习和静态页面不扣额度。它不是云厂商账单硬上限。请求频率/并发已有基础上限，尚不能按用户单独调整。

开发初值（未作容量结论，可在接入实际运行后调整）：

| 配置 | 初值 | 说明 |
| --- | --- | --- |
| `CLOUD_STORAGE_MB` | 256 MiB | 新账本的默认个人存储 |
| `CLOUD_DAILY_TRAFFIC_MB` | 256 MiB | 新账本的默认每日下载流量 |
| `CLOUD_MONTHLY_TRAFFIC_MB` | 1024 MiB | 旧接口兼容字段，不再执行个人月度限额 |
| `CLOUD_SITE_STORAGE_MB` | 5120 MiB | 云端账本的站点存储预算 |

个人默认额度第一次初始化后保存在数据库，随后通过后台调整；环境变量不覆盖已保存的默认额度。站点预算仍由部署配置提供。原有公共附件存储、站点下载预算另按原配置管理。

## 当前完成：AI 本地凭据设置

- 页面明确说明 Key 存在哪里、何时清除、题目作答发给谁，以及费用由用户承担。
- 默认 Key 仅在当前页面内存中；离开页面/退出账户后清除，不同步到 Hub。
- “记住此设备”用独立口令、PBKDF2-SHA256（600000 次、随机盐）和 AES-256-GCM（随机 IV）保存密文；不保存口令。密文绑定账户、网站 origin 和模型地址。
- 当前不使用 Hub 服务器保存 Key、不提供读取凭据的服务端接口、不设置服务器转发回退。
- 浏览器直连仅允许 HTTPS 模型基础地址，认证放在请求头，不放 URL 或提示词；禁止跟随重定向，不携带 Hub cookie，不展示供应商原始响应。
- 更换模型地址必须重新填写 Key。浏览器跨域不兼容时明确提示。
- AI 设置使用单独页面，脚本仅允许本站来源，不加载 Hub 注册界面的第三方验证脚本。
- 测试按钮会实际请求用户选择的模型服务，可能产生费用；已接通浏览器直连题目评分与文字、评分格式、图片识别测试。测试最多调用 3 次，未通过图片测试时不启用含图评分。
- 仅保存本地密文不能保护已解锁的 Key 免于设备失陷或恶意网页脚本。没有“Key 绝不泄露”或“全部责任归用户”的承诺。

## 当前完成：导入与拓展审核

1. 使用当前 `.qbank` 格式 3 与独立副本语义。每次导入分配新题库实例，不用 id/version 覆盖已有副本；保存 Hub 来源与 revision。
2. 先在有硬上限的临时目录解包；**在任何规则运行、目录计算或页面执行之前**验证拓展审核摘要。未知摘要拒绝云端执行。
3. 审核摘要独立于本地兼容性 fingerprint，涵盖拓展目录内每个文件，包括编辑器和未声明额外文件。只规范化 JSON 排版、清单展示名称与示例 JSON 的拓展相对绑定；规则、Schema、页面代码、声明、媒体字节与示例其他内容都进入摘要。相同 id/version 并不代表获准。
4. 固定快照包含四个基础拓展的摘要初值；数据库中已撤销的摘要不会在重启时自动恢复。撤销接口独立于公共发布审核。未知摘要拒绝导入；自定义摘要的人审提交、审阅和批准界面仍待完成。
5. 测量最终展开后的存储增量；在用户和站点预留成功后提交文件与账本，失败回滚。并发导入、保存、白板、图片、草稿、历史都必须进入同一配额边界，后台任务不得绕过。
6. 成功后删除上传原始 `.qbank` 和暂存文件；导出时从当前内容重新打包。满额时保留读取、导出和删除能力，不丢弃前端未保存输入。
7. 管理员交付记录真实操作者和所属用户；交付权限不自动开放私人作答/历史查看权。

## 当前完成：固定快照练习接入

- `node scripts/stage-cloud-runtime.mjs` 只读现有 `quizforge_web`，生成忽略于 Git 的 `.runtime/web-current/`。包含 host/web/shared、可移植运行依赖、四种基础拓展和官方演示题库，不复制用户数据或凭据。生成清单记录 HEAD 与当前工作区内容的 SHA-256；启动前验证快照所有文件。
- Hub 通过 `CLOUD_RUNTIME_DIR` 指向固定快照；更新本地源代码不会自动更改 Hub 正在使用的版本。正式打包必须同时携带该快照或用同一输入重新生成。
- 每个导入副本有独立物理目录、实例身份、练习/考试/历史/图片状态。每个请求再次通过 Hub 会话与所属用户检查，管理员身份不绕过私人练习所有权。
- 练习沿用固定 Web 代码。只适配静态入口与共享 API 前缀，不改本地 checkout。禁止云端调用本机管理、开发模式、原始库导入和服务端凭据接口；导入/导出统一走 Hub。
- 运行时最多保留两个打开的副本；练习请求进入有界串行队列。没有启动本地 host 的后台网络监听或服务端模型调用；自动评分任务由当前浏览器执行。考试截止在下一次考试请求时由既有内核推进。
- 每次练习 API 操作前建立独立磁盘检查点；返回成功前测量最终占用、预留增量并提交账本。超额会关闭对应运行时、恢复原文件，并向前端返回错误。异常退出后按 SQLite 日志恢复未提交检查点。此策略优先验证正确性，后续可用更细粒度写入事务替换整副本检查点。
- 读取原文件、导出、删除不要求额外个人存储额度；读取时的验证缓存和主机锁不计入个人账本。操作仍要求站点磁盘安全余量。缓存、回滚副本受平台磁盘余量保护，尚未做跨用户统一缓存淘汰。
- 支持私人上传、管理员交付、广场直接添加、独立示例、重复来源版本提示、导出和删除。原始 `.qbank` 不长期保留。

## 后续：评分与发布验收

- 继续验证完整考试、白板、编辑和冻结历史的浏览器行为；当前自动检查已覆盖真实题目读取、提交评分、持久保存、超额回滚、导出和其他账户越权拒绝，尚不能当作完整 UI/设备验收。
- 浏览器直连评分已实现：浏览器领取单次评分输入，直连模型，再提交结果；服务端沿用本地任务、小问、答案版本、题目版本、人工评分隔离与确认协议。Key 始终不传给服务端。页面关闭或任务超时后须明确手动重试，不自动重复模型调用。
- 补齐更细的用量分类、频率/并发定向管理、全站磁盘监控面板、自定义拓展人工审核工作流。
- 用两个账户验证题库、图片、作答、历史、考试、AI 任务和导出越权；验证恶意拓展在导入验证之前被拦截、撤销后冻结历史代码也停止执行。
- 核验重复导入、不同版本拓展并存、保存失败、额度耗尽、服务重启恢复以及完整 `.qbank` 往返；浏览器和真实设备验收单独记录。
- 首版暂不做大规模容量调优；仍保留有界队列、请求体/并发上限和磁盘安全余量。未压测前不宣称支持的用户数量。

## 隔离预览与测试

- 自动检查：`npm test`。所有数据均为临时合成数据，无真实 Key 或真实模型调用。
- 预览专用入口：`scripts/cloud-preview.mjs`；它不会由正式 `server.mjs` 启动，也不读取生产邮件配置。
- 必须显式设置 `PREVIEW_SYNTHETIC_DATA=1` 与 `DATA_DIR`，数据目录末级必须为 `quizforge-hub-cloud-test`。
- 预览仅监听 `127.0.0.1:4320`，使用独立合成用户、随机凭据及内存中的演示会话。顶部可切换管理员/普通用户，无需提供生产账户或密码。
- 示例 SSH 通道：`ssh -N -L 127.0.0.1:4321:127.0.0.1:4320 work-codex-seoul`，浏览器打开 `http://localhost:4321/cloud/`。
- 不应将演示代理暴露到公网，或使用它处理真实题库、真实 API Key。演示身份由代理在隔离环境中注入；正式用户授权仍只使用 Hub 的真实会话。
- 远程测试服务使用 `deploy/quizforge-hub-cloud-test.service`、独立系统用户与目录；没有生产邮件环境文件，不修改正式 Hub 的数据库、发布软链接或 Caddy 路由。

## 普通用户入口（2026-10-19）

- 新入口 `https://practice.treenewbee.cloud/`。独立进程 `quizforge-hub-practice`、系统用户 `quizforge-practice`、数据目录 `/var/lib/quizforge-hub-practice`，监听 loopback 4323。原正式 Hub 与合成预览实例继续独立保存。
- 登录复用原 Hub：刷题站生成随机浏览器校验 Cookie，跳到原域名 `/practice-auth/authorize`。已登录则使用一次性、60 秒有效的授权码返回；未登录则在原域名通过原 `/api/auth/login` 登录。不复制密码或直接打开生产数据库。
- 授权码绑定原刷题浏览器的校验 Cookie，消费后不能重放；只跳转固定刷题域名。刷题会话最多 12 小时，原 Hub 会话仅在服务器内存中关联，并在每次请求通过只读 `/api/me` 核验。服务重启后重新完成 Hub 跳转，作答数据不受影响。退出会同时撤销对应 Hub 会话。
- 只同步已验证登录用户的 id/name/email/admin 用于所属用户索引。本实例关闭本地注册/密码登录与公共分享路由，普通入口不展示管理员页面；广场仍在原 Hub。2026-10-20 已接通原广场“下载到云端”：登录后在练习域确认导入，通过文件与拓展校验后直接打开练习；已有同版本副本提供直接打开入口。
- 登录首次进入时幂等导入基础题库，并直接打开原 Web 刷题页；同用户重复请求共用初始化任务，不重置练习。不同用户各自独立副本。
- 云端 UI 在响应层适配固定快照：默认内置晨光湖畔背景、遮罩 15%、图片主题面板透明度 70%，已有浏览器选择继续保留。设置仅有用户中心、AI 评分和外观。左下获取题库指向原 Hub `/manage/#library`。
- 用户中心显示存储已用/额度及今日下载已用/额度。个人下载只执行北京时间每日限额；兼容保留旧月度统计字段，不执行个人月度限额。正常刷题、资源读取、保存及前端静态资源不扣下载额度；题库附件下载/导出计入。原站点/IP 文件预算仍保留。
- 私人题库与题库分组可以改名、移动和管理。运行时本机管理权限保持关闭，云端仅为所属用户开放 bank 类型的目录操作；拓展操作继续拒绝。修改进入原存储检查点和配额事务，并同步已安装题库目录缓存；失败回滚文件和记账。编辑弹窗按当前选择导出，走云端日下载记账，不调用本地导出接口。原生本机导入入口暂不展示。
- AI 设置以同源嵌入复用浏览器加密保险箱。评分调用留在设置 iframe；父页和题型 iframe 不接收 Key。支持手动、提交后自动、小问独立及交卷后评分、显式重试、人工评分，并保存最终结果。支持 JSON、严格 Schema 和文本兼容响应格式。配置与测试报告不随账户跨设备同步。
- 原 `quizforge_web` checkout 没有修改。移动端、白板、完整考试、浏览器交互及负载仍需单独验收；不标记为已完成的公开首版。
