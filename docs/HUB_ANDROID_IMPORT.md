# Hub → Android 一键导入入口

2026-10-21，本次仅调整 Hub 网页、说明和相关测试。未修改 Android、Web 主项目、服务端导入协议、登录或权限边界；未读取私有配置、运行数据或真实登录凭据，未部署。

## 页面行为

已审核公开 `.qbank` 的详情页依次提供三个入口，具体受既有本地、云端能力开关控制：

| 入口 | 行为 |
|---|---|
| 下载题库文件 | 沿用现有下载检查和文件接口，公开附件无需登录。未安装或未能唤起客户端时仍可使用。 |
| 下载并导入到本地 | “导入当前设备上的 QuizForge，支持电脑和安卓手机、平板。”使用真实的 `quizforge://` 链接，由当前设备系统选择已安装的处理程序，无平台选择器。 |
| 下载并导入到云端 | “导入账号的云端题库，需登录。”沿用原有云端导入和登录返回流程，不做本地与云端作答同步。 |

本地链接固定为 `quizforge://hub/import?v=1&pack=<小写 UUID>&revision=<正整数>`。网页不加入任意 URL、回调、Cookie、用户 ID、文件路径、命令参数或 API Key。点击后仅显示“已请求打开 QuizForge，请在系统提示中允许打开”，实际下载和导入结果由客户端报告。

不使用计时器、隐藏 iframe、循环尝试、localhost 探测或跨站回调推断安装、下载或导入结果。云端和本地入口仅针对已审核公开 `.qbank`；作者、管理员查看待审核或驳回附件时不能绕过该限制。其他格式保留原有文件下载权限。

安装区明确显示“安装／升级 Windows 版”和“Android 安装包待发布”。Windows 使用已有 `/` 下载指引；Android 当前没有链接，待正式发布地址及签名确定后再配置。未提供 `assetlinks.json`，未声称自定义 scheme 获得域名验证。

导入说明和状态置于独立容器，避免手机样式中隐藏直属 `.download-note` 的规则将它们隐藏。按钮插入顺序兼容本地增强和云端 MutationObserver 的先后顺序，重复增强不增加副本按钮。

## 协议与客户端边界

Hub 继续匿名提供 v1 清单及固定 revision、SHA-256 的附件，协议见 [导入协议 v1](superpowers/specs/2026-10-20-hub-local-import-design.md)。本次没有更改文件传输、流量计数、下架与版本竞态检查。客户端仍负责流式大小及摘要校验、取消、缓存清理和事务导入。

Android 接收、下载、导入和重复链接的实现进度来自交接：独立 Android 15 模拟器 `ACTION_VIEW` 下载公开包并导入 47 本；暖启动重复链接和飞行模式冷启动重复链接未创建副本。这些结果未在本任务重新验证，也不能替代实际浏览器或真机验收。Windows 与 Android 可以有各自的代理、去重和拓展能力边界，Hub 不为统一入口放宽客户端兼容要求。

原生账号登录授权留作后续协作；本次未添加移动登录 API、长期令牌、同步或 App Links。后续如需原生身份，应先约定固定官方 HTTPS 登录、短时一次性授权码、随机 state 与 PKCE、受限回跳、会话兑换/续期/退出/撤销和设备边界。保持离线免登录；现有网站 SSO 固定 origin 检查不因 appassets 而全局放宽。
