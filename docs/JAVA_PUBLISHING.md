# Java 题库分享与编辑

2026-10-25，第三阶段发布子模块。使用已确认的简洁原型，上传页和“我的分享”接真实接口。本轮随后已接管理员审核、拓展白名单和通知队列，见[管理与AI衔接](JAVA_ADMIN_AI_PRACTICE.md)；真实供应商及生产切换仍待验收。

## 页面

- `/#upload`：登录后选择题库文件、填写名称和介绍；版本、最多5个标签和6张截图选填。权利确认必须由用户勾选。
- `/#edit/<packId>`：仅原发布者可编辑，可保留原压缩包／截图，也可替换。不会改变发布者、题库ID、下载计数或已有评论。
- `/#mine`：按全部、已公开、审核中、未通过查询本人题库，过滤与分页在服务端执行。
- 文件选择阶段只在浏览器预览；提交时才上传，进度来自真实传输事件，成功提示等待服务端保存确认。离开未提交表单会询问，关闭页面使用浏览器原生未保存提示。
- 网络中断或超时不自动重试：结果可能已保存，提示用户先查“我的分享”，避免重复提交。

题库名称最多80个UTF-16代码单元，简介240、完整介绍12000、版本30、标签合计100。页面从介绍第一段生成列表简介，不截断保存的完整介绍。编辑旧长介绍时仍完整保留。

与原型中“修改时旧版继续公开”的演示文字不同，沿用现有Node实际行为：**新建、修改均进入待审；修改后审核期间暂停公开**。没有实现双份发布快照，不显示相反承诺。

## 接口

均为当前同源浏览器Cookie授权，不接受跨站写入。

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| POST | `/api/packs` | 新建，成功201 |
| PUT | `/api/packs/{id}` | 本人编辑，成功200 |
| GET | `/api/packs?mine=1&status=pending&page=1` | 本人的待审条目；status可省略或用approved／rejected |

上传使用`multipart/form-data`，字段为`title`、`summary`、`description`、`version`、`tags`（逗号分隔）、`rights=yes`、`keepScreenshots`（保留截图ID的JSON数组）。

- `archive`：新建必需，编辑可省略以保留原文件。
- `screenshots`：重复文件字段，新增截图按上传顺序追加；原有截图顺序不重新编排。
- `revision`：编辑必需，为打开编辑页时服务端给出的整数。与当前版本不一致返回409，不覆盖后来修改。
- 响应包含真实`pack`；状态pending，内部revision新建为1、每次编辑加1，面向用户的version仍由用户填写。

匿名与其他用户无法读取待审详情、目录、压缩包和截图。管理员可按既有权限查看待审条目，但上传编辑接口不会因此允许其冒充发布者编辑。

## 文件、事务与限制

- 支持`.qbank`／ZIP、7z、RAR，检查后缀及文件头。这里只存储，不解压或执行上传拓展；文件头检查不代表安全审核或已验证题库结构。
- 截图支持PNG、JPEG、WebP，检查后缀与文件头，不接受SVG／HTML。截图最多6张、每张3MiB。
- `MAX_ARCHIVE_MB`默认20，允许1至20；单请求上限40MiB、最多20个multipart项目，文件部分落磁盘而非整包进Java堆。
- `USER_QUOTA_MB`默认500，`TOTAL_QUOTA_MB`默认5000，按所有已登记附件的字节统计；更新按新增减去移除的差值计算。数据库事务内复查配额，不能靠并发超用。
- 同时处理一个上传保存；每用户每分钟最多6次，忙时503、频率超限429。登录、来源、本人归属检查先于延迟multipart解析。
- 存储文件使用宿主生成的不可变UUID文件名，原始名称仅作为元数据。新文件写入失败或事务回滚会清理本次已写对象。提交后才清除旧对象；清除失败不回滚已保存记录，可能留下不被引用的对象待后续清理。
- 同一事务写入元数据、附件引用、pending状态及`review_mail_state.generation`。保留旧通知队列语义；已接审核／审计与受限的提醒投递，需配置专用收件地址及真实供应商，未配置时不发。
- multipart超限返回413，无效表单400；存储故障不向客户端泄露路径或堆栈。没有关闭审核、放宽公共下载或提供任意文件路径操作。

## 验证范围

Java真实HTTP验证创建／编辑、匿名隔离、原文件保留及替换、评论与计数保留、过期revision、登录／来源／所有权、权利确认、文件头／大小／截图数量、账号和全站配额、停用及限流、失败文件清理。Node验证模板、转义和仅发布者出现编辑入口。测试站另以临时账号进行上传编辑和清理，具体结果见部署记录。

这些结果不替代真实浏览器、手机选择文件、拖放与视觉验收；当前浏览器工具在Work设置中禁用。

## 删除分享

`DELETE /api/packs/:id` 要求本人或管理员及同源请求，可提交 `{revision}` 防止过期删除。元数据、评论／举报与审核引用在事务中删除，再清理附件；已导入的练习副本保留。详情中删除需用户确认。
