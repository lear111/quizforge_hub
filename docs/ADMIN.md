# Hub 管理后台

入口：`https://quizforge.treenewbee.cloud/admin/`。右上角“管理后台”也可进入。没有登录时转到原 Hub 登录，普通用户不能访问管理数据。管理员仍由服务器上的 `scripts/admin.mjs promote` 明确授予。

## 功能

| 栏目 | 操作 |
| --- | --- |
| 总览 | 在线人数、日活、练习人数、新增和累计用户，7/30 天趋势，云端存储及待审量，文件下载预留量 |
| 邀请码 | 单个或批量生成，每码一次，设置有效期，当次完整码导出，查看兑换情况和停用 |
| 用户 | 按昵称/邮箱搜索，查看空间和今日下载用量，调整个人额度或恢复默认值，修改站点默认额度，封禁/解封，私人交付 |
| 题库 | 公共附件整包审核、驳回、下架、查看举报；通过 `.qbank` 整包审核时同时登记所审拓展的哈希 |
| 私人拓展验证 | 用户提交记录，管理员主动上传 `.zip` 或格式 3 `.qbank` 预审；查看代码/资源清单、批准或说明驳回原因 |
| 拓展白名单 | 全站共享的代码哈希批准记录，撤销批准；按批核对受影响的已安装云端副本及公共包记录 |
| 操作日志 | 操作者、对象、时间、原因和额度/审核/私人交付等变更 |

云端练习侧栏增加“切换”和“导入”。用户可上传私人 `.qbank`；未知拓展会拦截导入，用户可提交包内拓展审核。私人题库、作答和 API Key 不会因此公开，也不在后台提供查看入口。管理员交付给尚未访问过练习站的 Hub 用户也有效，空间记在接收用户名下。

## 审核与哈希

`.qbank` 只接受包内 `formatVersion: 3`，包括单题库包和分组包，明确拒绝旧格式 1、2。ZIP 是独立拓展压缩包入口，不是旧题库格式兼容入口。

待审包在独立隔离目录做有界静态解包。此过程不创建题库规则引擎、不执行待审 JS，不把代码插入网页。管理员选择文件时收到 JSON 文本，较大文本先显示前 512 KiB，并可下载所选完整原文件。批准前服务器重新计算摘要，拒绝快照变化后继续批准。

公共包保留原附件 SHA-256、版本和整包审核记录。拓展沿用 `qfh-extension-review-v1` 全文件清单摘要，包括题型页面、编辑器、规则、Schema、资源及未声明的额外文件；仅规范化清单 JSON 的格式/显示名称及示例中的导入绑定路径，以兼容导入时的文件夹更名。哈希一致只证明与已批准版本相符，批准本身由管理员检查代码完成。

管理员可以在“拓展白名单 → 添加 / 预审拓展”提前上传，未知哈希批准后立即全站可复用。名称或版本相同但内容改变需重新审核。已有批准的哈希直接显示匹配，不重复审批。全站白名单只共享安全审核结果，不共享私人文件，也没有增加未经约定的个人授权层。

私人 `.qbank` 提交后仅保留提取的拓展文件和审核元数据，删除题库内容与原始上传包。单包 64 MiB、单文件 8 MiB、解压 128 MiB、每包最多 64 个拓展；待审文件总预算 512 MiB，最多保留 200 条记录，每用户最多 10 个待审申请。第一版到达预算会明确拒绝新增，不自动清理历史记录。

撤销哈希后后续导入和练习请求会再校验并拦截，保留原题库和作答。已经呈现在浏览器中的页面不会被远程清除。受影响副本列表每批核对 50 个已安装副本，支持继续核对下一批，避免一次扫描全站文件阻塞服务。

## 统计与额度

统计按北京时间。在线是最近 5 分钟有前台活动的去重账号；DAU 是当天实际进入页面的账号；练习 DAU 来自翻题/考试操作或成功提交作答请求。前台心跳只维持在线，不制造 DAU；后台接口轮询不产生访问事件。每个账号在两个站点去重，部署前未采集的活跃数据不补造，页面显示采集起点。

下载统计合并广场附件和云端导出在发送前的保守预留，包含中断请求，不能作为云厂商账单。普通练习不扣个人下载额度；用户界面和管理表单只提供空间与每日下载额度，不提供个人月度额度。已有站点传输预算仍保留。

封禁会删除该用户全部 Hub 会话；练习站每次请求向 Hub 核实登录，因此旧练习登录也随之失效。解封不恢复已撤销的会话，需要重新登录。不能封禁当前正在操作的管理员。

## 双服务配置

原 Hub 与练习服务代码使用同一个 Hub 发布提交，但练习仍使用固定 Web 运行时快照。此次没有修改或重新打包本地 `quizforge_web`。

两个 systemd 服务均设置：

```ini
[Service]
Environment=ADMIN_ENABLED=1
Environment=PRACTICE_ADMIN_PORT=4324
```

原 Hub 对外仍为 4318，练习为 4323，新增管理桥只绑定 `127.0.0.1:4324`，不要在 Caddy 中暴露。Hub 后端将现有管理员会话通过环回网络提交给桥；桥逐次向固定 Hub `/api/me` 核实角色。管理员向新用户交付或调额度时，桥再向 Hub 核实目标账号身份。练习服务不直接打开原 Hub 数据库、不复制密码，不创建额外管理员共享密钥。

原有练习站公网 `/api/cloud/admin/*` 继续关闭。后台写接口同时检查 Hub 管理员、同源写入、参数和限流；待审文件不在静态目录中。两个站点继续保留独立服务用户和数据目录。

发布前在新目录检查完整测试，保留原 Web 快照及摘要；停止两个服务后备份数据与旧服务配置，再切换发布目录。健康检查练习环回端口时必须带 `Host: practice.treenewbee.cloud`。失败恢复原发布目录和管理开关，不删除当前用户数据。备份包含用户资料，需只允许服务器管理员访问。

## 验证范围

`test/admin.test.mjs` 使用合成账号与临时目录，实际启动两个 HTTP 服务及私有桥，验证角色/同源限制、邀请码、封禁同步、新用户额度、待审规则不执行、文件变更拦截、完整原文件读取、整包批准登记哈希、接收用户记账和隔离、额度不足回滚、撤销后的导入/运行拦截、影响列表、真实去重统计。

浏览器布局、实际管理员登录后的点击和真实手机/平板体验需另行验收；DOM 模拟及 HTTP 测试不等同于浏览器验收。测试不读取真实用户会话、不发送注册邮件、不调用付费 AI，也不自动批准线上待审拓展。
