## 保留的云端差异

- 设置沿用 Hub 账号、浏览器本地 AI 配置（自定义模型）、账号免费 AI 额度和云端用量；隐藏本机网络与拓展开发设置。外观仍默认图片主题、遮罩 15%、面板透明度 70%；新增青屿的初始默认值为 30%、65%。保存过的主题和遮罩优先，不主动切换主题；两种插画间切换保留自定义图片和各主题面板偏好。
- 本地文件导入使用 Web 原有的一个按钮、文件选择器和确认弹窗。未知拓展在运行前验证完整审核摘要，可在同一弹窗提交审核，不增加第二套导入器。
- 公共题库下载和管理员私人交付追加到同一账号工作区。Hub 导入完成后使用 Web 已有的 `imported-bank` 定位机制打开新题库。重复 Hub revision 打开已有内容；显式独立副本继续生成独立题库 ID。
- 保存的题库、图片、答案、合成 PNG、回收内容和历史纳入账号存储。题库导出继续计下载流量，日常刷题和保存不计下载流量。账号鉴权、同源检查和拓展摘要撤销保持有效。

除这些适配外，直接使用完整 Web 运行快照。新增 Web 模块需要一起同步依赖，不能只复制可见页面或为了通过测试删掉入口。

## 旧云端空间合并

普通练习服务启用一个账号一个工作区；旧预览实例的隔离导入接口保持兼容。升级时以最早的基础空间为主，将旧独立导入加入原生题库列表。题库实例文件不重新生成，拓展包代码不改写，只调整必要的相对绑定和拓展示例状态定位。

合并在现有检查点事务内完成：文件冲突、摘要撤销、配额或保存失败时回滚目标；旧目录不删除、不改写。数据库保留旧导入到工作区的所有权映射，旧链接继续访问。已合并的旧目录作为平台恢复副本保留，不重复计入用户逻辑用量；实际磁盘仍需为它们及事务备份留空间，清理应另行评估。

同路径资源只有字节一致才合并，状态冲突不会覆盖。题库与拓展示例的作答、冻结历史、图片和删除收据保留。合并无法识别的遗留结构会明确拒绝并保留原件，不能以重导入或清空数据替代迁移。

## 构建及检查

本次候选应使用下列命令：它从指定 Git 提交重建源码，再应用 Hub 内冻结、逐文件核验的覆盖，避免直接带入 Web 工作区后续变动。需保留可访问指定提交的 Web Git 仓库和目标平台的依赖目录。

```text
node scripts/stage-web-workspace.mjs <Web Git仓库> <新的运行时目录> <目标平台node_modules目录>
```

生成的 `snapshot.json` 记录提交、`includesWorkingTree: true`、覆盖文件摘要及完整来源清单摘要。默认使用 20261027-network 清单并核对全部253项源码／基础内容；可通过第4个参数指定旧清单。Linux候选必须使用Linux依赖重新构建，不能复用Windows原生模块。

在目标平台准备 Web lock 对应的依赖，再使用新目录构建：

```text
node scripts/stage-cloud-runtime.mjs <Web源码目录> <新的运行时目录> [显式node_modules目录]
```

目标包含 `@napi-rs/canvas` 1.0.12 及匹配 OS/CPU/libc 的原生模块。Linux 快照必须在 Linux 构建；启动校验拒绝跨平台快照，并校验每个文件的摘要。Linux 原生二进制约 35 MiB，专用上限为 64 MiB，其他运行文件仍为 32 MiB；用户上传和格式 3 包的限制不变。

Windows 测试可设置 `QFH_TEST_RUNTIME` 指向新候选。`test/workspace-parity.test.mjs` 要求答题区候选存在；迁移用例另需旧 `.runtime/web-current`。缺少运行时导致的跳过不等同于验收通过。

最新候选可执行 `pwsh -File scripts/Verify-Java-Hub.ps1 -SkipBuild -PracticeRuntime .runtime/web-sync-20261027-network`；`-SkipBuild`只适用于Java源码未改且已有匹配JAR的情况。需要测试旧候选时，同时用 `QFH_TEST_SOURCE_LOCK` 指定其锁定清单，避免拿新清单验证旧快照。

界面DOM检查依赖JSDOM。验证脚本会优先复用相邻Web的现有开发依赖，也可用 `-UiPackage <含JSDOM依赖的package.json>` 显式指定；它只用于测试，不进入运行包。仍需核对结果中的跳过项，缺少DOM依赖不能视为界面验收通过。

发布前必须在目标 Linux 上确认可用的中文和西文字体。最初首尔隔离检查只有 DejaVu；随后经授权部署，已安装 Noto CJK 与 fontconfig，并用练习服务账号生成中英文字体检查图片，人工查看中文显示正常。详见[部署记录](../deploy/archive/workspace-2026-10-21.md)。仍需实际浏览器验证答题区文字/手写/图片、手机触控、单题编辑离开拦截和原生文件选择。模型检查使用合成响应，不代表真实供应商已调用。
