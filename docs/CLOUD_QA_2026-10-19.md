## 首尔 HTTP 主流程

`node scripts/check-cloud-preview.mjs http://localhost:4321` 已实际运行通过：

1. 共用 Hub 登录与管理员/普通用户权限隔离。
2. 创建并审核合成公共题库，再由普通用户直接添加到自己的云端。
3. 内部导入增加用户存储，不作为公共下载出口流量重复收费。
4. 重复来源版本返回 409，要求打开已有副本或显式选择新副本。
5. 管理员访问普通用户的私人练习路径返回 404。
6. 云端练习 HTML 与固定 API 适配资源可读。
7. 读取真实示例题，提交正确答案，保存后读回 `submitted` 状态。
8. 禁止服务端 Key 读取接口。
9. 从已安装内容重新生成 `.qbank` 并下载。
10. 重启测试实例后，再次读取相同题目：状态 `submitted`、revision 1、得分 2，持久化恢复成功。
