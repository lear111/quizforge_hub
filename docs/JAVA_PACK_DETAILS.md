# Java 题库详情、目录与选择下载

2026-10-25，第三阶段中的详情页子模块。真实发布／编辑／下架、审核管理和练习衔接仍按后续模块迁移，能力接口不将它们标为完成。

## 页面

沿用确认原型的页头、作者／版本、介绍、包含题库、截图、交流反馈及获取题库侧栏。包含题库从实际附件读取，默认展示前8本，可展开全部、逐本选择或全选；数量表示实际题卡数，不估算拓展评分规则对应的总分。

全选时直接下载原附件；选择部分时生成格式3 ZIP容器。单本标记`scope: bank`，多本为分组包，保留所选题库文件夹及原配套拓展分组。配套拓展暂整组携带，不做依赖裁剪。题库JSON、图片、拓展规则及资源字节不改写，仅调整包清单的范围；导入器仍按原规则分配本地实例与重写安装路径。

所选包大小在生成前未知，界面显示“打包后下载”。侧栏SHA-256明确标注为原整包校验值，不将它冒充所选包的摘要。

云端练习导入、客户端一键导入、编辑与下架仍显示当前可用状态，不因新增目录接口自动开放。没有启用任意URL代理、练习SSO或未审核拓展运行。

## 目录与下载接口

| 接口 | 行为 |
| --- | --- |
| `GET /api/packs/{id}/catalog` | 沿用公开／所有者／管理员可见性，返回原修订号、原附件SHA-256及真实题库列表 |
| `POST /api/packs/{id}/download-selection` | 同源JSON，校验修订号、摘要与所选题库，流式返回`.qbank` |

目录返回结构：

```json
{
  "available": true,
  "revision": 1,
  "sha256": "原附件SHA-256",
  "banks": [{ "id": "目录项不透明标识", "title": "示例题库", "questionCount": 8 }]
}
```

目录项ID由包内准确路径生成，仅用于本次目录定位，不替代题库原ID；`version`仅在题库自身明确提供时返回。只把`question-banks/<分组>/<题库>/bank.json`计入目录，拓展示例不计入。

选择下载JSON为`{revision, sha256, banks:[目录项ID]}`。空选择、重复／未知ID返回400，修订号或摘要不一致返回409。私有题库对无权限访问返回404，格式或包结构不支持返回422；界面保留整包下载和目录重试。

保留现有整包`download-status`和`download`行为。选择下载按实际生成字节数预留站点／IP及已启用的账户额度，题库下载计数同事务更新；预算失败回滚并清理临时包。已开始下载后中断的预留按原语义保留。

## 评论与举报

| 接口 | 参数与返回 |
| --- | --- |
| `POST /api/packs/{id}/comments` | `{body}`，1–2000个UTF-16代码单元，201 `{comment}` |
| `DELETE /api/comments/{id}` | 评论作者或当前管理员可删除，200 `{ok:true}` |
| `POST /api/packs/{id}/report` | `{reason}`，1–1000个UTF-16代码单元，201 `{ok:true}` |

写操作要求已登录、精确同源及未封禁账号；评论／举报还要求题库已审核公开。登录与权限检查由服务器执行，写事务内复查账号封禁和题库状态；删除时使用当前数据库管理员标记。评论每用户每分钟10次，举报5次。

沿用24KB JSON上限、重复键拒绝和原错误结构。评论、作者与目录文字按纯文本转义，删除和举报分别要求用户确认／填写原因。没有将举报内容自动投递到邮件或外部平台。

## 文件边界

只读取数据库选定的`files/`附件，校验真实路径、大小与原SHA-256。读取／复制ZIP条目及JSON，不解压到任意路径，不执行包内JS。限制压缩包64MiB、单文件8MiB、展开总量128MiB、10000条目、256本题库；拒绝越界、无效或大小写重复路径，读取条目时核对长度和CRC。

目录缓存最多8份，以附件身份、SHA-256和修改时间区分；同时只展开一份目录并允许有限等待。选择包写入受限数据目录，最多2个在途任务，单个输出64MiB，上下文结束或失败时清理，不将大包整体保留在JVM堆中。
